# v0.28.0 — BPD-Strict Rebuild

**Date:** 2026-08-15
**Status:** Approved (user green light on 2026-08-15)
**Author:** Mavis
**Scope:** Single release. No follow-ups bundled.

## Goal

Make MindAnchor BPD-strict on the surfaces the user actually opens during a
crisis window (00:00–05:00, on a bad day, on a relationship rupture, on a
"should I text them" moment). Every change must be traceable to a research
paper or to an existing BPD-safe design pattern. No treatment claims. No
hardcoded crisis line numbers (R1 honored).

## What ships in v0.28.0

### A. Four new research-grounded surfaces

All four are code-complete as of 2026-08-15. v0.28.0 wires them in, ships
them, tests them.

1. **Distress Thermometer** (Linehan 1993 + Gross 1998)
   - Single Composable, 0–100 slider, four banded suggestions:
     - 0–30 → body-first grounding
     - 31–60 → affect labelling (Lieberman 2007)
     - 61–85 → TIPP
     - 86–100 → "talk to a person who knows you" (no numbers — R1)
   - State: `var current by rememberSaveable { mutableStateOf(50) }`
   - No log, no save, no chart.
   - FindingTest: `DistressThermometerFindingTest.kt` (~4 tests)

2. **Letter to a Part** (Schwartz 1995 — IFS)
   - Three sub-screens via `private enum class LetterScreen { PICK, TO, FROM }`.
   - Pick from five named parts (angry / scared / wants-to-disappear / critic
     / protector) + "other".
   - Optional free-text in TO and FROM.
   - `rememberSaveable` for rotation; no DataStore write.
   - FindingTest: `LetterToPartFindingTest.kt` (~5 tests)

3. **ACCEPTS** (Linehan 1993 ch. 8 — Distress Tolerance, self-soothing)
   - Seven-button grid (ACTIVITIES / CONTRIBUTING / COMPARISONS / EMOTIONS /
     PUSHAWAY / THOUGHTS / SENSATIONS) via
     `private enum class AcceptsLetter { ... }`.
   - Tap one to read the body. Back to return to the grid.
   - No save. No log.
   - FindingTest: `AcceptsFindingTest.kt` (~3 tests)

4. **DBT Diary Card** (Linehan 1993 ch. 11)
   - Five fields per day: urge / emotion / intensity (0–10, DBT convention) /
     skill used / outcome.
   - Per-day DataStore key: `diary_card_<yyyy-MM-dd>` via JSON in a single
     String preference.
   - Weekly view rendered as a **list**, never a chart (BPD-safe per audit
     §2.3 — chart implies interpretation the project is not allowed to make).
   - `DiaryCardPrefs.kt` is the data layer.
   - FindingTest: `DiaryCardFindingTest.kt` (~5 tests)

### B. One novel research addition

5. **Opposite Action** (Linehan 1993 ch. 8)
   - The genuinely new piece in v0.28.0. Not a textbook surface; a small
     structured walk through the four-step skill:
     1. Name the emotion.
     2. Check if it fits the facts.
     3. Identify the action urge.
     4. Do the opposite.
   - One-screen Composable, optional free-text per step, no log, no score.
   - ~80 LOC + 1 FindingTest (~3 tests).
   - Sits between TIPP and Self-compassion in the Support group.

### C. Home redesign — Distress Thermometer first

**Current order (v0.27.0):**
OpenLoop / QuickNotes / OneThing / Right now (3 BPD entry points at the bottom)

**New order (v0.28.0):**
1. **Distress Thermometer** (primary, first card on home)
2. OpenLoop
3. QuickNotes
4. Right now (3 BPD entry points)

- `OneThingCard` is **removed from home** but the data model, the
  `bedtimeList` state flow, and the existing notes-flow entry point are
  kept. Single source of truth: the `OneThingStore` and the OneThing data
  class. No DataStore write is removed.
- The Distress Thermometer card on home opens `DistressThermometerActivity`
  on tap.
- `home_distress_card_title` = "How is it right now?"
- `home_distress_card_caption` = "Slide to where it is, not where you want
  it to be. There is no right answer."

## Privacy

BPD is private to the user. The release notes, README, and any PR
description must not name BPD. Frame as "research-grounded mental-health
features" with a citation to the audit doc.
